# AuthLock

## 项目名称：AuthLock
## Slogan：Edit freely, credit stays.

### 定位
Windows 离线版权隐形指纹保护工具，纯本地、无网络、无联网、无OSINT、无爬虫、无搜索、无上传、无比对、无外部API、无数据库、无数据收集、无自动发送，仅本地文件处理。

### 技术栈
- Node.js 20.x LTS
- Electron 30.0.0（固定版本）
- sharp 高性能图像处理
- 原生 HTML/CSS/JS
- Tailwind CSS v3（CDN）
- Fluent Design 深色亚克力风格
- 全程离线、安全、健壮

### 功能特性

#### 1. 图片隐形指纹植入（LSB隐写）
- LSB最低有效位隐写，肉眼不可见
- 四角+中心五区域冗余嵌入，抗剪裁、抗局部覆盖
- 嵌入：author、rootHash(SHA256)、timestamp、version
- 支持 PNG、JPG、JPEG、BMP
- 自动处理色彩空间，无画质异常

#### 2. 指纹提取与验证
- 五区域读取，任一区域成功即可恢复完整信息
- 自动校验完整性与篡改状态
- 绿色=正常，红色=被篡改
- 清晰展示作者、时间、原始哈希、当前哈希

#### 3. 根哈希计算（区块链级确权）
- SHA256 唯一标识，不可篡改

#### 4. 合规维权模板生成（仅本地生成）
- DMCA 国际投诉模板
- 中国版权投诉模板
- 自动填充信息，可保存为 txt/md
- 不联网、不发送、不提交

#### 5. Windows Gui
- Fluent Design 深色亚克力风格
- 左侧导航 + 右侧内容区
- 卡片式布局、圆角、阴影、柔和过渡
- 支持图片拖放，带拖拽反馈动画
- 清晰按钮、状态提示、加载动画
- 结果排版专业、易读
- 全流程不崩溃、不卡顿、无白屏

#### 6. 汉堡菜单功能
- 支持侧边栏的显示/隐藏
- 提供更灵活的界面布局

#### 7. 首次启动用户名设置
- 首次启动时要求填写用户名
- 仅用于本地水印生成，不上传服务器
- 自动填充到相关输入框

### 安装与运行
1. 确保已安装 Node.js 20.x LTS
2. 克隆项目到本地
3. 进入项目目录
4. 运行 `npm install` 安装依赖
5. 运行 `npm start` 启动应用

### 使用方法
1. **嵌入指纹**：点击左侧导航栏的「嵌入指纹」，选择或拖放图片，填写作者信息，点击「嵌入并保存」
2. **验证指纹**：点击左侧导航栏的「验证指纹」，选择或拖放图片，系统自动提取并验证指纹
3. **生成维权模板**：在验证指纹后，点击「生成维权模板」，选择模板类型，填写相关信息，点击「生成并保存」
4. **批量处理**：点击左侧导航栏的「批量处理」，选择多个图片，填写作者信息，选择保存目录，点击「开始批量处理」

### 安全说明
- 本工具完全离线运行，所有处理均在本地完成
- 不会收集、上传或分享任何用户数据
- 不会连接任何外部API或服务
- 所有文件处理均在本地文件系统进行
